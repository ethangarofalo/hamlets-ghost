# Contributing

Hamlet's Ghost is currently a single-operator research instrument under active methodological development.

Issues, reproduction reports, methodology questions, and evidence proposals are welcome.
Pull requests should start as an issue first unless the change is a small documentation correction.

Good contributions make the instrument more honest:

- clearer reproduction steps
- better tests for epistemic guardrails
- tighter documentation around implemented versus aspirational behavior
- concrete evidence proposals with falsifiable claims

Please avoid broad rewrites, hidden policy changes, or changes that make the lab sound more certain than its evidence allows.
